# 快捷键与排障

[English](shortcuts.en.md) · [快速上手](../README.md)

## 写公式

| 操作 | 用法 |
| --- | --- |
| 新建公式 | 在命令面板运行 **插入行内公式** 或 **插入块级公式**。也可以先选中同一文本块中的内容，再用命令把它包成公式。 |
| 自动展开 | 在闭合的公式中输入触发串。用 `@a` 输入 `\alpha`，用 `sq` 插入根号，用 `sr` 加平方上标。 |
| 手动展开 | 输入手动触发串后按 **Tab**，例如输入 `\sum` 再按 **Tab**，补出求和上下限。也可将手动触发键设为 **空格键**。 |
| 填写占位点 | **Tab** 前进，**Shift+Tab** 后退，**Esc** 结束跳转。相同编号的占位点会联动，例如同时更新环境的开始和结束名称。 |
| 快速输入分式 | 在空公式中输入 `//`，依次填写分子和分母。已有分子时，可直接输入 `/`。例如 `(a+b)/` 会变成 `\frac{a+b}{}`，光标停在分母。 |
| 矩阵和对齐 | 在块级公式中输入 `pmat`，填写矩阵时按 **Tab** 插入列分隔符 `&`，按 **Enter** 插入 LaTeX 行分隔符 `\\`，按 **Shift+Enter** 跳到环境的结束命令之后。也适用于配置中的环境，例如 `cases` 和 `align`。 |
| 跳出括号或公式 | 按 **Tab** 跳过右括号或公式的闭合定界符。若光标右边已有配对的右括号，也可以输入同一个右括号跳过去。 |
| 选中或加框 | 光标放在公式内，运行 **选中当前公式** 或 **给当前公式加框**。选区不包含定界符，加框会用 `\boxed{…}` 包住公式正文。 |

默认情况下，**Tab** 依次尝试手动展开、占位点跳转、矩阵快捷键和跳出括号或公式。都不适用时，由笔记处理 **Tab**，例如缩进列表项。把手动触发键改成空格后，**Tab** 从占位点跳转开始。

块级公式可以在同一文本块内分行。光标在矩阵等快捷环境之外时，可用 **Shift+Enter** 插入源码换行。矩阵中用 **Enter** 插入的 `\\` 则用来分隔排版后的行。跨段落的美元定界符不会组成同一条公式。

## 常见问题

**输入触发串后没有反应。** 先用命令插入一对定界符，在中间逐字键入 `@a`，确认插件已启用且自动展开没有暂停。单个开头的 `$`、转义的 `\$` 和代码里的美元符号都不会打开公式。行内公式的定界符内侧不要留首尾空格。粘贴和输入法组词期间不会触发自动展开。自定义片段还要检查当前库、模式和触发键。

**正文中的 `mk`、`dm` 没有创建公式。** 在命令面板用插入公式命令。如果习惯在正文中用自动片段，可在插件设置的 **片段**中开启 **正文自动片段**。这个开关也控制 `\text{…}` 等公式内文本环境的自动片段。正文手动片段仍可用所选的手动触发键。

**想临时停用自动展开。** 在命令面板运行 **暂停 LaTeX 自动展开**，结束暂停时运行 **恢复 LaTeX 自动展开**。暂停期间，自动片段、自动分式和键入右括号跳出都会停用。手动片段和已打开的占位点仍可使用。

**刚刚展开了不想要的片段。** 在继续输入或移动光标前，按 **Backspace** 或运行 **还原刚刚展开的 LaTeX 触发串**。刚输入的完整触发串会恢复，包括触发展开的最后一个字符。

**Tab 跳到了别处。** 先检查是否还有片段占位点，或光标是否在启用快捷键的矩阵环境内。按 **Esc** 可以结束当前占位跳转。若想从公式中间直接跳出，可检查 **Tabout** 中的 **仅在行尾跳出公式** 设置。

**公式显示成了源码。** 先检查定界符及 LaTeX 语法。公式预览默认由 Forsion 提供。宿主没有原生公式预览时，可在插件显示设置中启用隐藏 LaTeX 语法。光标离开公式时，部分命令会显示为符号，进入公式即可编辑源码。

**外部文件已保存，片段没有更新。** 运行 **重新加载 LaTeX 片段**，再检查插件设置中的路径和错误提示。配置无法加载时，插件继续使用本次运行中上一份有效的片段库。文件格式及目录规则见[自定义片段与迁移](custom-snippets.md)。
