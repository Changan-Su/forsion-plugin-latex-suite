# 自定义片段与 Obsidian 迁移

[English](custom-snippets.en.md) · [快速上手](../README.md)

## 选择片段来源

打开 **LaTeX 套件**设置，在 **片段**中选择 **片段库来源**。

- **插件内正文**使用设置页里的代码编辑器。可在已有数组中追加片段，也可替换整个数组。恢复默认前，先复制一份自己的片段。
- **单个文件**使用库内路径，例如 `LaTeX/snippets.js`。文件内容是一份片段数组。
- **整个文件夹**从指定库内目录及其子目录读取 `.js` 和 `.json` 片段文件，将各文件的数组合并。变量文件单独配置，放在片段目录之外。

用外部来源时，插件内正文仍保留。**教程与练习**页会显示当前宿主支持哪些文件改动自动重载，也可点 **重新加载片段**手动刷新。遇到路径、读取或解析错误时，先根据 **片段**页的提示修正，再重新加载。

- 片段和变量均配置在插件内时，插件可在重启后启用已保存的上一份有效配置，同时保留当前内容供修正。
- 片段或变量来自外部文件时，重载失败会继续使用本次运行中上一份有效的库。重启后重新从当前库读取外部文件。

## 编写片段

片段库可以是 JSON 数组或 JavaScript 数组表达式。JavaScript 格式允许写正则字面量、注释和函数。只加载来源可信的 JavaScript 片段，因为插件会执行其中的代码。

```js
[
  {trigger: "@a", replacement: "\\alpha", options: "mA"},
  {trigger: "ff", replacement: "\\frac{$0}{$1}$2", options: "m"},
  {
    trigger: /([A-Za-z])(\d)/,
    replacement: "[[0]]_{[[1]]}",
    options: "mA",
    excludedMacros: ["ce", "pu"],
  },
  {trigger: "U", replacement: "\\underbrace{${VISUAL}}_{$0}", options: "mAv"},
]
```

这组示例可以单独作为一个小片段库。输入 `@a` 会自动得到 `\alpha`。输入 `ff` 后按手动触发键会得到分式。在公式里选中一段内容后键入 `U`，会给选区加下括号。

| 选项 | 含义 |
| --- | --- |
| `m`、`n`、`M` | 分别表示任意公式、行内公式、块级公式。 |
| `t` | 适用于正文和公式中的文本环境，例如 `\text{…}`。两处的自动展开都需要开启 **正文自动片段**。 |
| `A` | 输入完整触发串后自动展开。省略时用设置中选定的手动触发键。 |
| `r` | 将字符串触发串当作正则表达式。使用正则字面量时可省略。 |
| `w` | 要求触发串两侧为词边界。词分隔符可在高级设置中调整。 |
| `v` | 使用选区。自动选区片段用单字符触发，`${VISUAL}` 代表选中的文本。替换字符串包含 `${VISUAL}` 时可省略 `v`。 |

JavaScript 字符串中的 LaTeX 反斜杠要写成 `\\`。替换文本中的 `$0`、`$1` 等按数字顺序跳转，`${0:x}` 给第一个占位点预填 `x`。`[[0]]`、`[[1]]` 等引用第一个、第二个正则捕获组。替换函数可返回字符串或 `false`，返回 `false` 会跳过这条匹配。

触发串冲突时，`priority` 值较大的优先。优先级相同则先试较长的触发串。`description` 可说明用途。用 `excludedMacros: ["ce", "pu"]` 跳过这些宏的参数，用 `excludedEnvironments: ["align"]` 跳过指定环境。

普通或正则片段可用 `triggerAfter` 匹配并替换光标右边的一段文字。比如 `trigger: "qq", triggerAfter: "?"` 会要求右边紧接 `?`，展开时一起替换 `qq` 和 `?`。如果是正则片段，`triggerAfter` 也按正则匹配，捕获占位符只引用左侧触发串。选区片段不支持这个字段。

## 配置片段变量

在 **高级**的**片段变量**中编辑 JSON 对象，或配置一个库内变量文件。键名含 `${…}`，值是字符串。例如添加 `"${VECTOR_AXIS}": "(?:x|y|z)"` 后，可用 `"(${VECTOR_AXIS})vv"` 作为正则触发串。默认变量包括 `${GREEK}`、`${SYMBOL}`、`${MORE_SYMBOLS}` 和 `${ACCENT}`。自定义值可覆盖同名的默认变量。

## 从 Obsidian 迁移

1. 从原配置复制片段数组。若文件含有 Markdown 围栏、模块导出或额外脚本语句，先把片段整理成单个数组表达式。复制片段变量时使用 JSON 对象。
2. 把片段贴到 Forsion 的内置编辑器，或保存为库内文件并选用该来源。手动设置触发键和显示偏好。
3. 检查下表中的语法差异，再到 **教程与练习**试用常用触发串。若依赖 `mk` 或 `dm`，开启 **正文自动片段**。

| 上游写法或能力 | 在 Forsion 中的处理 |
| --- | --- |
| 每条片段的 `triggerKey` | 移除此字段，手动片段统一使用设置中的 **Tab** 或 **空格键**。 |
| `c`、`C`、代码语言筛选、`math` 代码围栏 | 代码块和行内代码按字面量处理。公式功能使用配对的美元定界符。 |
| `T` 文本宏专用模式、`includedMacros` | 这两项暂不支持。`t` 同时适用于正文和公式内文本，`excludedMacros` 用于排除宏。 |
| `U` 撤销标志 | 可以保留。撤销由 Forsion 编辑器处理。要立即恢复自动展开前键入的完整触发串，用 **Backspace** 或恢复触发串命令。 |
| 函数返回 LuaSnip 风格的节点 | 将返回值改为含占位点的字符串，或用 `false` 跳过匹配。 |
| Vim 快捷键、多光标占位 | 使用 Forsion 的快捷键。同编号占位点通过一个光标同步文本。 |
| 跨段公式、按 LaTeX 构造还原源码 | 多行块级公式需要留在同一文本块内。启用隐藏 LaTeX 语法后，光标进入公式时整条公式还原为源码。 |

上游语法以 [Obsidian LaTeX Suite 1.12.8 文档](https://github.com/artisticat1/obsidian-latex-suite/blob/8498f43/DOCS.md)为参照。
